## Follow this Link - https://react.dev/reference/react/Fragment

1. <div></div>
Use case:

When you need a wrapper for styling, layout, or DOM structure.
When you want to apply a class, id, or style to a group of elements.


2. <React.Fragment></React.Fragment>
Use case:

When you want to group multiple elements without adding extra nodes to the DOM.
Useful in lists, tables, or when returning multiple elements from a component.


## 3. <>...</> (Fragment shorthand)
Use case:

Same as React.Fragment, but with shorter syntax.
Use when you don’t need to add keys or attributes to the fragment.
